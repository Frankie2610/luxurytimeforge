# Luxury TimeForge V0.65.0

## Storefront polish
- Redesigned `Xem tất cả` actions with a flatter dark-green premium treatment and a separated gold arrow affordance.
- Reworked the `100% / 1–4 ngày / Dài lâu` facts into solid deep-green, burgundy and ochre cards with explicit white foregrounds.
- Removed the legacy `tf582-storefront-pills` strip (`Chính hãng / Thanh toán an toàn / Theo dõi đơn hàng / Hỗ trợ sau bán`).
- Reduced section spacing on phones while preserving the 366–520px two-column product grid and <=365px single-column fallback.
- Restyled installment planning to a flatter luxury UI: ivory/white surfaces, thin lines, dark segmented controls and a restrained gold accent.
- Refined the Warranty page with a smaller hero title, quieter surfaces and tighter typography.

## Newsletter fixed end-to-end
- Replaced the old no-op `preventDefault()` form with `NewsletterSignupV65` used across the live theme section, footer and popup.
- Explicit dark foreground, caret and autofill colors prevent white-on-white typing.
- Inline `Đang gửi / Thành công / Đã đăng ký / Thất bại` feedback with `aria-live`.
- Writes newsletter subscribers to Firebase and waits for the write result before showing success.
- Added `/api/newsletter/subscribe` for server-side Firebase persistence when server Firebase credentials are available.
- Optional Resend confirmation email and optional admin notification through Vercel environment variables.
- Split newsletter actions into a narrow context so newsletter interaction does not subscribe to the full Commerce context.

## Two new customer tools
1. **Tư vấn kích thước cổ tay** — customer selects wrist circumference and receives a suggested case-size range; compares it with the current product when case-size data is available.
2. **Báo khi giá giảm** — customer can register an email and 5/10/15% threshold. Records are saved to `timeforge/priceAlerts`; public users can create but not read the alert database. After an Admin product save, `/api/price-alerts/process` reads the current Firebase price, emails eligible subscribers through Resend, then marks delivered alerts as `notified` to avoid duplicate sends.

## Admin polish
- Brighter white/green palette with stronger page headers, cards, buttons, inputs, tables, focus states and upload controls.
- Structural layout ownership remains route-safe to avoid the V0.63 lazy-CSS regression.
- Added **SEO Google** fields under basic store settings: homepage SEO title and meta description are stored in Firebase.
- Existing Messenger/Zalo social-share-image control remains supported.

## Google SEO
- Dynamic canonical, robots, Open Graph/Twitter metadata and route-specific titles/descriptions.
- Product `Product/Offer`, `BreadcrumbList`, `Organization`, `WebSite`, `CollectionPage/WebPage` JSON-LD.
- Dynamic `/sitemap.xml` through `/api/sitemap`, sourced from current Firebase products and collections.
- `robots.txt` points to the sitemap and excludes non-index pages such as Admin/Checkout/Account.
- Optional `VITE_GOOGLE_SITE_VERIFICATION` hook for Search Console verification.
- Homepage SEO title/description can now be maintained from Admin; product SEO continues to use per-product fields.

## CSS optimization
- V0.64 baseline: 142 CSS files / 1,278,930 bytes / 2,695 `!important` declarations.
- V0.65: 117 CSS files / 862,226 bytes / 2,445 `!important` declarations.
- CSS source reduced by **416,704 bytes (32.58%)** while adding the V0.65 features.
- 26 runtime-unreferenced legacy stylesheets (~425 KB) removed; exact list is in `docs/CSS_DEAD_FILES_V65.json`.
- Runtime import graph has no missing CSS references and no unreferenced CSS leftovers found by the V0.65 audit.
- Avoided cross-route “winner” pruning on Admin CSS. Only route-safe/component-owner cleanup and proven-dead-file removal were used.

## Deployment notes
- Deploy the full project to Vercel, not only `dist`, because newsletter/social-image/sitemap APIs live under `/api`.
- Deploy the updated Firebase rules for `priceAlerts`.
- For server newsletter persistence and full dynamic sitemap, configure `FIREBASE_DATABASE_URL` and `FIREBASE_DATABASE_AUTH` on Vercel.
- For confirmation emails configure `RESEND_API_KEY` and `NEWSLETTER_FROM_EMAIL` (optional: `NEWSLETTER_REPLY_TO`, `NEWSLETTER_NOTIFY_EMAIL`).
- For Search Console meta verification configure `VITE_GOOGLE_SITE_VERIFICATION` at build time.
