# Luxury TimeForge V0.56.0

## Storefront Wishlist

- **Share list:** creates a normal `/wishlist?wish=...` link for up to 24 published products. Desktop copies the link; supported mobile browsers open the native share sheet.
- **Safe import:** opening a shared link merges valid products into the existing device-local Wishlist, removes duplicate IDs and keeps the 100-item storage limit.
- **Compare products:** customers can select up to three saved products and compare price, brand, type, stock and SKU in a responsive dialog.
- Comparison controls stay inside the product-media area, avoiding title and cart-action collisions on narrow screens.

## Admin orders

- **Time range filter:** adds Today, last 7 days and last 30 days. The selected range remains in the URL alongside status, payment and search filters.
- **Copy current view:** copies a deep link containing the exact active order filters, including a search value that has not finished its debounce yet.
- Existing order rows remain real links and workflow data remains normalized before order-detail filtering.

## Admin density

- The account menu now toggles table density between Comfortable and Compact.
- The preference is stored as `tf:admin-density` in localStorage.
- Compact mode changes only data tables, avatars and table badges; editor forms keep touch-friendly control heights.

## Performance and layout safeguards

- New Wishlist and Admin rules are isolated in `v560-wishlist-features.css` and `v560-admin-features.css`.
- Wishlist cards use offscreen rendering containment with an intrinsic fallback size.
- New overlays avoid backdrop blur and disable animation when reduced motion is requested.
- Dedicated desktop, tablet, mobile and narrow-mobile layouts protect toolbar and comparison geometry.
