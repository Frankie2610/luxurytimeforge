# TimeForge Sprint 28

Sprint 28 tập trung vào độ dễ đọc và độ hoàn thiện giao diện.

- Chuẩn hóa typography storefront bằng Inter/Manrope fallback, tăng độ đậm tiêu đề và body.
- Tăng khoảng thở hai bên trang sản phẩm, card hóa buy panel, mô tả, thông số và giao hàng.
- Footer nền tối luôn dùng chữ sáng; newsletter có input/border/focus rõ ràng.
- Modal tìm kiếm và newsletter đóng khi click khoảng trống.
- Collection filter dùng backdrop toàn viewport và drawer full height.
- Journal được thiết kế lại theo layout editorial tương phản cao.
- Checkout chia ba bước thành card, input rõ border, payment state, sticky order summary và trust strip.
- Căn lại Admin topbar và Theme Editor topbar, giữ nút Lưu nằm đúng tâm header.
