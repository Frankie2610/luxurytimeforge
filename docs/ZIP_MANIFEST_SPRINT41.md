# Sprint 41 ZIP manifest

The archive includes:

- React/TypeScript source for the storefront, checkout, admin and Shopify-inspired Theme Editor
- Sprint 41 stylesheets (`v41-storefront.css`, `v41-checkout.css`, `v41-admin.css`, `v41-theme-editor.css`)
- Production build in `dist/`
- Firebase rules example and project configuration
- CSS and dead-code audit reports for Sprint 41
- Windows start scripts and project documentation

The archive intentionally excludes `node_modules`. Install dependencies with pnpm before development.
