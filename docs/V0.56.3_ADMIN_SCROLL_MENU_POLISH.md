# V0.56.3 — Admin scroll, Menu and Wishlist polish

## What changed

- Product Detail now scrolls as one page. The former independently scrolling right column is part of the normal document flow.
- Online Store overview now scrolls as one page. Its desktop and mobile preview iframes are non-interactive, do not expose internal scrollbars and no longer intercept pointer input.
- Theme Editor still supports separate tree, inspector and settings scrolling, but those secondary scrollbar rails are hidden.
- Storefront Menu locks the root and body before paint, compensates for scrollbar width, uses an immediate tablet/desktop reveal and a short transform-only mobile transition.
- Wishlist selected sorting text uses 11px on desktop, 10.5px on tablet and 10px on mobile; the opened option list retains its readable sizes.
- Dense Product Editor and Theme Editor labels, inputs and descriptions are slightly larger and remain responsive.

## New utilities

- Product Editor quick-jump navigation for Content, Media, Pricing, Inventory, Variants, SEO and Status.
- `Ctrl/⌘ + S` saves the current product.
- Browser refresh/close warns when product edits have not been saved.
- Storefront Menu exposes correct expanded/control accessibility state and includes Track Order.
