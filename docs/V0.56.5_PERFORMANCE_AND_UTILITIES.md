# Luxury TimeForge V0.56.5

This release focuses on interaction latency rather than adding heavy visual layers.

## Performance changes

- Commerce theme objects are memoized, so cart state updates stay inside the dedicated cart contexts.
- Wishlist data uses `useSyncExternalStore`; product cards subscribe to one boolean instead of the full list.
- Product cards are memoized and no longer re-render together when a different Wishlist item changes.
- The storefront entry no longer imports Framer Motion for the hero, collection cards and product gallery fade.
- Replacement motion only animates `opacity` and `transform`, with a reduced-motion fallback.
- Sticky/fixed customer layers no longer blur the entire page during scroll or drawer transitions.

## New customer utility

Search keeps the six most recent non-empty terms on the current device. Terms are deduplicated case-insensitively, can be reopened with one tap and can be cleared without affecting products or account data.

## New Admin utility

Product Editor includes **Sao chép link** beside the public preview and save actions. It copies the canonical storefront URL when the Clipboard API is available and falls back to a selectable browser prompt.
