# V0.56.4 — Wishlist, footer, Admin and performance polish

## Responsive Wishlist dropdown

- Desktop: selected value and opened options use `12px`.
- Tablet (`<= 1024px`): selected value and opened options use `11px`.
- Mobile (`<= 640px`): selected value and opened options use `10px`.
- The selected value uses the storefront UI sans-serif stack rather than inheriting the larger editorial heading face.

## Product Detail Admin

- The long right column has a dedicated thin scrollbar at desktop widths from `921px` upward.
- The scrollbar is bounded to the viewport, keeps the column sticky and prevents scroll chaining into the page at its edges.
- Tablet and mobile switch the column back to normal document flow to avoid a nested touch-scroll surface.
- The new Product Readiness panel shows completion progress and links directly to incomplete sections.

## Storefront identity and utilities

- Header and navigation copy use `13px` consistently.
- The footer displays the resolved Admin-managed store name at `16–18px` with a strong weight.
- Product Detail includes a Share action using the platform share sheet when available and a clipboard fallback elsewhere.

## Performance safeguards

- Header, mobile drawer and footer logo instances receive store identity as memoized props instead of subscribing independently to the complete commerce context.
- Search and filter overlays no longer apply a full-page backdrop blur.
- New visual transitions use short compositor-friendly properties and honor reduced-motion preferences.
