# V0.56.2 — Cart, mobile menu and Wishlist refinement

## Wishlist

- The sort control uses 12px text on desktop, 11px on tablet and 10px on mobile.
- The select has a consistent custom chevron, compact label/icon spacing, hover feedback and a keyboard focus ring.
- The final Wishlist media layer removes padding from the wrapper, smart-image span and image itself.
- Product images remain square and center-cropped edge to edge.
- The hero now has a clearer editorial accent, calmer count panel and smaller mobile typography.

## Cart performance

- Cart state lives in its own context, separate from catalog, collection, theme and Admin data.
- Quantity updates now notify cart readers only; product cards that only need `addToCart` consume a stable actions context.
- The cart drawer builds a memoized product lookup map and memoizes line totals.
- Drawer thumbnails request 320px images instead of 900px and load lazily at low priority.
- Full-cart rows no longer run Framer Motion layout measurement after every quantity change.
- Product media, copy and price blocks stay centered across desktop, tablet and mobile layouts.

## Mobile menu and cart drawer

- Both drawers use short CSS animations limited to `transform` and `opacity`.
- Overlay backdrop blur was removed to reduce GPU/compositor cost on mobile devices.
- Drawer surfaces use paint/layout containment and scroll containment.
- Escape closes either overlay and body scrolling is locked only while an overlay is open.
- Reduced-motion users receive no drawer animation.
