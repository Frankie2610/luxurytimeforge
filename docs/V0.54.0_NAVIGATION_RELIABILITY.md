# V0.54.0 — Navigation reliability, performance and scoped polish

## Root cause of the Admin order error

The route itself was working. Opening `/admin/orders/:id` mounted the order-detail component, then the component called `.filter()` on one of the workflow collections. Records created by older versions can omit `refunds`, `returns` or other workflow keys, so that collection was `undefined` and React stopped rendering the route.

V0.54.0 normalizes every workflow read and write into this stable shape:

```ts
{
  events: [],
  fulfillments: [],
  refunds: [],
  returns: [],
}
```

Firebase objects stored as keyed maps are also converted to arrays. The same defensive normalization now covers the other persisted datasets most likely to have mixed historical shapes.

## Admin improvements

- Order numbers and open-order controls are real React Router links.
- Order search, status and payment filters are stored in the URL and can be bookmarked or shared.
- Priority Center links open the already-filtered order list.
- The command palette can search recent orders by number, customer, email or phone and open them directly.
- A route-level recovery surface offers reload, back and dashboard actions if an unexpected record still breaks one Admin screen.
- Product thumbnails use lazy loading and asynchronous decoding.
- Dashboard metric/trend spacing was corrected without changing the Admin shell.

## Storefront improvements

- Product pages show up to four recently viewed products.
- History is stored only on the current device, is capped at eight IDs and can be cleared by the customer.
- The added section uses the existing product card/grid components, so it inherits the stable storefront design and breakpoints.

## Responsive and layout strategy

No new global theme override was introduced. V0.54.0 CSS is limited to the new recently-viewed section, the Admin route recovery surface and small Orders/Dashboard refinements. Existing tablet/mobile breakpoints remain the source of truth; new controls add their own narrow-screen rules at 700/680 px.
