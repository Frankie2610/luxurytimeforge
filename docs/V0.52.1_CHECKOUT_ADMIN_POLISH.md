# Luxury Timeforge V0.52.1 — Checkout and Admin polish

## Storefront
- Header logo enlarged; fallback store name is 26px on desktop.
- Navigation remains 13px on desktop without forcing the store name down to 13px.
- Home and collection banners use 80% of the configured height.
- Footer payment marks are more compact.

## Bank transfer checkout
- Bank information is displayed as a structured payment card.
- Account number and transfer content have copy actions.
- Preview format: `TFYYMMDD-SKU`.
- Final server-generated format: `TFYYMMDD-SKU-####` to avoid duplicate references.
- Successful bank-transfer orders show a toast asking the customer to transfer with the exact content and wait for Admin confirmation.

## Admin
- Topbar groups have consistent height, spacing and contrast.
- Order payment details use a clearer bank card and financial summary.
