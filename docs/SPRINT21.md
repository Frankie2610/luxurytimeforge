# Sprint 21 changes

## Storefront

- Increased side margins on wide desktop screens with a 1360px editorial content canvas.
- Equalized Add to cart and Buy now button widths.
- Moved payment, shipping and warranty cards under the product gallery.
- Removed duplicate delivery/warranty accordions from the right purchase panel.
- Improved product service cards, product typography and responsive spacing.
- Reduced Journal article title and hero image scale.
- Improved Story page heading scale.
- Increased contrast for dark hero/editorial sections.

## Admin

- Product images continue to use dnd-kit drag sorting.
- Added a “View on storefront” action in the product editor.
- Refined Admin topbar search, data mode, create action, store link and user menu.
- Rebuilt Settings cards into a balanced responsive grid.
- Stabilized the Online Store editor topbar and Save action.
- Reworked the Blog editor dialog into a two-column desktop editor and one-column mobile editor.
- Added overflow containment and long-text protection across Admin surfaces.
