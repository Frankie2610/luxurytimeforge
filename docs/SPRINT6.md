# Sprint 6 — Admin UI parity

Version: 0.6.0-alpha.1

## Scope
- Rebuilt admin shell with compact dark command bar and neutral application sidebar.
- Added store switcher, status indicator, notification control, user avatar and global search shortcut treatment.
- Normalized page width, spacing, cards, buttons, inputs, badges, data tables and editor panels using a Polaris-inspired density system.
- Improved products table, product editor and theme editor visual hierarchy.
- Added tablet/mobile adaptations for the admin shell and editor.

## Accuracy note
This is a TimeForge implementation inspired by Shopify Polaris interaction and density conventions. It does not copy Shopify trademarks, proprietary assets, or exact source code.
