# Luxury TimeForge V0.56.6

## Footer identity

- Removed the duplicated footer logo/name lockup that created two shop-name lines.
- Kept only the store name resolved from Admin settings.
- Increased the desktop name scale from the previous 16–18px range to 24–30px, with 950 weight and black text.
- Added a direct **Theo dõi đơn hàng** service link.

## About page polish

- Reduced the hero, story-section and closing CTA title scales.
- Tightened vertical spacing and reduced the decorative mark size.
- Added a lightweight three-card trust layer for authenticity, decision support and after-sales care.
- Added direct shortcuts to warranty policy and order tracking.
- Applied `content-visibility` only to below-fold story articles to reduce initial paint work on long content.

## Customer utilities

- Added a compact fixed utility dock after the customer scrolls down:
  - **Theo dõi đơn**
  - **Về đầu trang**
- Scroll visibility uses one passive listener plus `requestAnimationFrame`, avoiding layout work on every scroll event.
- Smooth scrolling is disabled automatically for reduced-motion users.

## Admin utilities and polish

- Added a recent-pages dropdown containing the five latest Admin screens, persisted on the current device.
- Added **Sao chép link trang hiện tại** for faster collaboration and support.
- Refined topbar, page-header, card, table and active-navigation surfaces.
- Added sticky table headers to large scrollable data tables.
- Applied targeted below-fold rendering containment to long Admin pages; it is disabled on mobile.

## Bottlenecks addressed

- Removed duplicated footer DOM and the grid rules needed only for that duplicated lockup.
- Avoided new backdrop blur, large animation libraries or continuous scroll state updates.
- Kept changes in isolated final cascade files instead of increasing specificity across older CSS layers.
