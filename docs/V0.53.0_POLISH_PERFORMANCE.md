# Luxury TimeForge V0.53.0

## Customer storefront

- Refined the visual language around a deep forest, warm ivory and restrained gold palette.
- Rebalanced headings, body copy, navigation, cards, product detail, footer and page spacing.
- Added a persistent wishlist that synchronizes across tabs and is available from the header, mobile menu, product cards, product detail and `/wishlist`.
- Added complete keyboard focus treatments and reduced-motion behavior.
- Added responsive behavior for wide desktop, tablet, mobile and narrow mobile layouts.

## Admin

- Unified sidebar, top bar, page headings, cards, forms, tables, badges and action buttons.
- Added an Operations Pulse dashboard with current-month metrics and seven-day revenue comparison.
- Added a Priority Center for unfulfilled orders, pending payments, low stock, out-of-stock products and unpublished products.
- Added direct quick actions for product creation, order review, theme editing and storefront preview.
- Improved tablet navigation and mobile table/form behavior.

## Performance

- Removed `legacy.css` from the storefront's static import graph, eliminating a 45.61 KiB gzip stylesheet from customer-route loading.
- The production manifest reports 56.62 KiB gzip of CSS in the storefront's current static graph.
- Removed header typography DOM mutation that previously caused repeated inline style writes during layout.
- Applied `content-visibility`, containment and intrinsic sizing to suitable offscreen customer/Admin sections.
- Kept the wishlist page route-lazy; its generated chunk is approximately 1.44 KiB JavaScript and 2.09 KiB CSS gzip.
