# Luxury TimeForge V0.53.1 — Layout stability correction

V0.53.1 is a corrective release for the visual regressions introduced by the broad V0.53 storefront and Admin CSS layers.

## What changed

- Removed `v53-storefront-polish.css` and `v53-admin-polish.css` from the source.
- Restored the existing storefront compatibility stylesheet so the proven V0.52.7 layout remains authoritative.
- Restored the Atelier theme defaults used by the Theme Editor preset.
- Added only two isolated enhancement files:
  - `v531-storefront-additions.css` for the wishlist badge and accessibility focus.
  - `v531-admin-dashboard.css` for Operations Pulse and Priority Center.
- The isolated additions total 9.9 KB raw, compared with 37.7 KB raw for the removed global overrides.

## Features retained

- Persistent wishlist state and the `/wishlist` page.
- Wishlist actions in product cards and product detail.
- Admin Operations Pulse, seven-day revenue comparison, Priority Center and quick actions.
- Reduced-motion support and mobile-safe controls.

## Validation

- TypeScript typecheck and production build.
- V0.52.1 through V0.52.7 regression suites.
- V0.53.1 layout-stability checks.
- Responsive grid, Admin CSS, authentication-session, content-page and dead-code checks.
