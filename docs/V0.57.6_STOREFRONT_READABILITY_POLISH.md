# Luxury TimeForge V0.57.6

## Storefront readability

- Added a final responsive typography owner so legacy 5–8px labels no longer win the customer-facing cascade.
- Raised product card, PDP, footer, search, policy, About, Wishlist and Journal supporting copy while preserving compact hierarchy.
- Kept the intentional product grid contract: 366–520px uses two columns; 365px and below uses one column.
- Unified existing cards and pills with warm-neutral borders, practical spacing and accessible focus states.

## Compare

- Preserved one horizontal comparison table for all selected products.
- Added concise helper pills for the comparison model: same row, separate criteria and live catalog data.
- Increased mobile row labels, values, actions and helper copy.
- Fixed production CSS pruning by emitting explicit `count-1`, `count-2` and `count-3` class names. This keeps the 2/3-product min-width rules in deployed builds.

## Cart and checkout

- Added a semantic three-step cart journey: Cart, Checkout and Confirmation.
- Refined cart line items, quantity controls, save/remove actions, trust cards, delivery progress and order summary.
- Fixed the mobile checkout action following the viewport by returning it to normal document flow.
- Increased checkout action type to 13px and retained a 54px touch target.
- Reworked checkout inputs with clearer labels, optional-field pills, improved placeholder contrast and visible hover/focus/autofill states.
- Repaired the mobile brand rail so the complete card remains visible and only the brand pills scroll horizontally.
