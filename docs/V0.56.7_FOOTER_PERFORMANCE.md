# Luxury TimeForge V0.56.7

## Footer

- Restored the configured shop logo in the footer.
- The logo component no longer renders its own text label in the footer, so the editable store name remains the only name line.
- The store description is omitted when it only repeats the store name, including case-only differences.
- The editable store name remains black, extra bold and larger, while the logo and name use a responsive two-column layout.

## Storefront performance

- Replaced checkout-wide relational `:has(...)` selectors with an explicit `is-checkout-route` class.
- Added responsive Cloudinary `srcset` generation for hero, collection, editorial, video-poster and collection-banner images.
- Cached product-family lookup by the current catalog references, replacing repeated group scans on every product card.
- Indexed product-group resolution by product ID and SKU.

## Admin performance and polish

- Replaced the global `body:has(.v16-admin-shell)` selector with a lifecycle-managed `tf-admin-mounted` class.
- Delayed hover-prefetch by 140 ms and cancelled it when the pointer leaves, avoiding unnecessary chunk requests while moving through the sidebar.
- Kept recent-page navigation, sticky table headers, lighter cards and below-fold paint containment from V0.56.6.
