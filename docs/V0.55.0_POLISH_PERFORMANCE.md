# Luxury TimeForge V0.55.0

## Admin polish

- Order search, payment filter and action buttons now use a responsive grid instead of competing flex widths.
- Search controls use dedicated icon, input and clear-button tracks, preventing text or controls from overlapping.
- The same input rhythm is applied to product, customer, inventory, discount, return and draft-order searches.
- Order search waits briefly before updating the URL, supports `/` to focus and Escape to clear, and preserves direct-linkable filters.
- The current filtered order set can be exported as CSV.
- Order detail normalizes workflow data again before reading it, protecting direct links from incomplete legacy/Firebase records.

## Storefront and Wishlist polish

- Wishlist product media is square, centered and never forcibly circular; images use `object-fit: contain` and `object-position: center`.
- Mobile Wishlist cards use a compact horizontal layout with smaller headings, labels and controls.
- Customers can sort saved products, add every available item to cart, or clear the list.
- Sort preference and Wishlist IDs remain device-local.

## Performance work

- Product and Wishlist lookups use memoized maps/derived lists.
- Storefront search results and customer-segment membership are memoized.
- Wishlist persistence is deferred to avoid synchronous storage writes during the click frame.
- Storefront query changes no longer remount the route view or trigger the pathname scroll-reset effect.
- Admin and Wishlist routes prefetch on pointer intent or keyboard focus.
- Mobile/touch layouts disable expensive blur and hover transforms; media surfaces use paint containment.
