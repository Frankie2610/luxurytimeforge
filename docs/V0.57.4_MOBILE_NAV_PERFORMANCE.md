# Luxury TimeForge V0.57.4

## Responsive storefront

- Product grids retain two cards per row from **366px to 520px**.
- The single-column product layout now starts at **365px and below**, instead of 379px.
- Below 380px, product titles, prices, badges, section descriptions and collection controls receive one small typography reduction without changing tablet layouts.
- The responsive owner stylesheet is loaded after the historical storefront layers, preventing older media queries from winning the cascade.

## Header polish

- The sale/free-shipping announcement uses a solid `#b4232f` red background and white icon/text.
- Desktop and narrow-desktop main-navigation links are fixed at **13px** from 821px upward.
- The new rules use the existing Header IDs, so they consistently override legacy 10–11px declarations without changing the mobile drawer.

## Performance

- Home Journal cards are no longer statically imported by the shared storefront route.
- An `IntersectionObserver` starts loading the Journal module only when its reserved shell is within 480px of the viewport; browsers without the API load it normally.
- Responsive skeletons reserve the future card height, limiting layout shift while the small async chunk arrives.
- Production manifest verification:
  - V0.57.3 storefront static JS graph: **194.71 KiB gzip**.
  - V0.57.4 storefront static JS graph: **193.15 KiB gzip**.
  - Reduction on the shared static graph: **1.56 KiB gzip**.
  - Deferred Journal cards + blog data: **2.39 KiB gzip**, requested only near the section.
