# Luxury Timeforge V0.64.0

## Mục tiêu

V0.64 ưu tiên khôi phục độ ổn định của Admin sau đợt CSS cleanup V0.63, tiếp tục giảm CSS trùng theo cách an toàn với route/lazy stylesheet, đồng thời chỉnh contrast và polish các component storefront được phản hồi.

## 1. Admin layout recovery

- Khôi phục nhóm stylesheet lõi của Admin về baseline V0.62 đã ổn định trước khi tiếp tục tối ưu.
- Không còn dùng chiến lược loại declaration theo "winner toàn cục" xuyên nhiều route/lazy stylesheet.
- `v620-admin-polish.css` là lớp final owner cho layout/control Admin:
  - khóa `min-width: 0` cho main/page/content để tránh grid/flex overflow;
  - chốt width/max-width/padding ở một owner cuối;
  - chuẩn hóa input/select/textarea/file input;
  - focus ring, disabled state, placeholder và contrast;
  - primary/secondary/danger button và descendant `span/svg`;
  - mobile form font-size 16px để tránh iOS auto zoom;
  - card/table/toolbar/topbar được polish lại.

## 2. CSS optimization V0.64

Tối ưu được đổi sang hướng route-safe/structural-safe:

- Chỉ dedupe declaration giữa các stylesheet Admin **luôn đồng thời được load**.
- Không dedupe xuyên CSS lazy theo route.
- Structural optimizer chỉ:
  - gộp rule liền kề cùng selector;
  - gộp rule liền kề có declaration giống nhau;
  - gộp at-rule liền kề cùng điều kiện;
  - bỏ comment/whitespace không cần thiết;
  - không reorder selector/rule.
- Repeated selector optimizer chỉ gộp khi không có declaration can thiệp làm thay đổi cascade.

V0.64 vẫn nhỏ hơn V0.63 khoảng 3.9 KB dù đã phục hồi CSS Admin ổn định và thêm polish mới. So với V0.62, tổng CSS giảm khoảng **350.6 KB / 21.52%**.

`!important` tăng nhẹ so với V0.63 do phục hồi các rule contrast/layout Admin cần thiết từ baseline ổn định và chốt một số foreground bị mất contrast. V0.64 không đánh đổi layout để giảm chỉ số này.
