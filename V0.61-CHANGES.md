# Luxury TimeForge V0.61.0

- Review saves now await the Firebase write before the admin reports success, so a local-only review cannot masquerade as persisted.
- Fix testimonial/review flash: public Firebase refresh no longer wipes a valid published cache when the public query returns an empty payload; testimonial cards are removed from `content-visibility` containment.
- Polish managed and fallback testimonial layouts with lighter cards, clearer hierarchy, compact numbering, mobile layout fixes, and stable normal paint flow.
- Fix storefront contrast for `tf-section-action-v4912` including its legacy child `<span>`, plus the assurance strip (`100% / 1–4 ngày / Dài lâu`) and related storefront actions.
- Add `socialShareImage` to Store Profile and Admin Settings. Admin can paste a URL or upload an image; it is stored in Firebase and Cloudinary.
- Social preview priority: `socialShareImage` → Firebase shop `logoImage` → `/social-cover.jpg`.
- Add `/api/social-image` image proxy so Messenger/Facebook/Zalo crawlers receive an actual image directly from static Open Graph HTML without requiring React/JavaScript execution.
- Static `og:image`, `og:image:secure_url`, and Twitter image now use `/api/social-image?v=61`.

## Deploy

Deploy the full Vercel project so the new `/api/social-image` serverless function is available. Keep `VITE_FIREBASE_DATABASE_URL` or `FIREBASE_DATABASE_URL` configured in Vercel. After changing the share image, social networks may keep their own cached preview for a while; the endpoint itself uses a short 5-minute CDN cache.
